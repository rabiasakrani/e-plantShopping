# e-plantShopping

## Paradise Nursery Shopping Application

**e-plantShopping** is a React-based shopping cart application for an online plant nursery called **Paradise Nursery**.

The application allows users to browse a variety of house plants, view plant details and prices, add plants to a shopping cart, update item quantities, remove items, and view the total cart cost.

### Features

- Landing page for Paradise Nursery
- Product listing with different plant categories
- Plant images, descriptions, and prices
- Add to Cart functionality
- Shopping cart quantity management
- Increase and decrease item quantities
- Remove products from the cart
- Dynamic total cart cost
- Continue Shopping and Checkout options
- Redux-based state management

### Technologies Used

- React
- JavaScript
- Redux Toolkit
- HTML
- CSS
- Vite
